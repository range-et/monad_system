Monad System Standards Manual

Monad

A unified visual communications system for software.

The compiler reads one source file, colors.json. It writes themes and tokens for CSS and JavaScript, Unity, Python, Streamlit, SwiftUI, VS Code, Ghostty, Xcode, Sublime Text, draw.io and C++/Arduino.

1

Tiers

The system has four layers. Each layer has one job and one prefix.

1.1

Strata

--strata-*

CSS custom properties for colour, spacing, type and motion. All other layers read their values from these tokens.

1.2

Monad

.monad-*

Classes for page structure: shell, grid, header, rail and content area.

1.3

Atomos

.atomos-*

Classes for components: buttons, cards, tags, callouts, forms, tables and progress bars.

1.4

Threshold

.threshold-*

Classes for navigation and state changes: menu toggle, rail drawer and transitions.

3

Rules

Form follows function. If it doesn't serve a function, delete it.

3.1

Shape

Use square corners. Do not use border radius.

3.2

Depth

Do not use gradients or decorative shadows. Use layer steps and rules to show hierarchy.

3.3

Motion

Use 80 ms linear transitions for state changes. Do not animate elements for decoration.

3.4

Colour

Components do not contain hardcoded colours. Each colour comes from a --strata-* token.

3.5

Type

Set text in Helvetica, flush left, in sentence case. Use mono only for data: values, IDs, code and timestamps.

3.6

Scope

Keep decoration out of the system. Use borders only to separate content.

5

Perception benchmark

Saliency models predict where a user looks first.

#1
First of five systems

The benchmark has 45 layouts: 5 systems × 3 form factors × 3 scenarios. Two independent saliency models (UMSI++ and DeepGazeIIE) score each layout on two metrics (mass-on-target and z-scored NSS). Monad has the best mean rank across the four lenses (2.00) and the most per-cell wins (11 of 36). Material 3 is second (2.25). Material has the higher mass-on-target on both models.

6

Quick start

Link the CSS and JavaScript files. Use only tokens in your own styles.

6.1 HTML
<!-- 1. Link the system -->
<link rel="stylesheet" href="build/monad.css">
<script src="build/monad.js"></script>

<!-- 2. Shell -->
<header class="monad-header">
  <span class="monad-header__name">App</span>
  <button class="strata-toggle" data-mn-theme-toggle>◑</button>
</header>

<!-- 3. Components -->
<button class="atomos-btn atomos-btn--primary">Action</button>

<!-- Custom styles: only use --strata-* tokens -->
<style>
  .my-component {
    background: var(--strata-layer-01);
    border-top: 1px solid var(--strata-border);
    color: var(--strata-text-primary);
    transition: background var(--threshold-fast);
  }
</style>
